**Project Overview**

This project focuses on Explainable AI (XAI) for Graph Neural Networks (GNNs), using the CEPS algorithm and subgraph extraction techniques to interpret AI-driven drug recommendations.

Using PrimeKG, a biomedical knowledge graph, the project aims to identify and visualize the key biological substructures and relationships that contribute to a GNN's prediction of a specific drug for cancer treatment.

Rather than treating the model as a black box, the goal is to extract a small, informative subgraph containing the most influential nodes and edges behind a prediction. This subgraph serves as an interpretable explanation, helping researchers and medical professionals understand the evidence underlying the model's recommendation.

The project explores the use of GNNExplainer and graph-based explanation methods to identify relevant substructures and present them through visualizations.

**Main Objectives**

Apply explainability techniques to GNN-based drug recommendation.

Extract relevant subgraphs from PrimeKG to explain model predictions.

Identify influential biological entities and their relationships.

Visualize the extracted subgraphs to make model decisions more interpretable.

Provide a more transparent basis for understanding AI-assisted drug recommendations.
